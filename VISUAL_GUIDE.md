## ❌ Типичные ошибки

### Ошибка 1: Использовать название вместо ID

```
❌ НЕПРАВИЛЬНО:
┌───────────────────────────────┐
│  /update Ярина плюс 19:30     │  ← Бот не поймет!
└───────────────────────────────┘

✅ ПРАВИЛЬНО:
┌───────────────────────────────┐
│  /list                        │  ← Сначала узнаем ID
│  /update 2 19:30              │  ← Используем номер
└───────────────────────────────┘
```

### Ошибка 2: Забыть указать время

```
❌ НЕПРАВИЛЬНО:
┌───────────────────────────────┐
│  /update 2                    │  ← Нет нового времени!
└───────────────────────────────┘

✅ ПРАВИЛЬНО:
┌───────────────────────────────┐
│  /update 2 19:30              │  ← ID + новое время
└───────────────────────────────┘
```

## 💡 Частые вопросы (FAQ)

**Q: ID — это название таблеток?**  
A: НЕТ! ID — это НОМЕР напоминания. Используйте `/list` чтобы узнать.

**Q: Как написать `/update Ярина плюс 19:01`?**  
A: НЕПРАВИЛЬНО! Сначала `/list`, потом `/update 2 19:01` (используя номер).

**Q: Как не держать компьютер включенным?**  
A: Разместите бота на VPS-сервере → [HOSTING_GUIDE.md](HOSTING_GUIDE.md)
