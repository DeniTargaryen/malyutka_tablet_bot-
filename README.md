## 🚀 Быстрый старт (локально)

⚠️ **Внимание:** При локальном запуске бот работает только когда ваш компьютер включен!  
💡 **Рекомендуется:** Разместить бота на сервере → [Гайд по хостингу](HOSTING_GUIDE.md)

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка

Создайте файл `.env` с токеном вашего бота:

```
TELEGRAM_TOKEN=ваш_токен_от_BotFather
```

### 3. Запуск

```bash
python bot.py
```

📖 Подробнее: [Быстрый старт](QUICK_START.md)

## 📱 Команды бота

- `/start` — начать работу с ботом, показать справку
- `/setme` — настроить стандартные напоминания:
  - 06:00 МСК — Эсциталопрам (утро)
  - 19:00 МСК — Ярина плюс (вечер)
- `/list` — показать все напоминания с их ID
- `/settime HH:MM [метка]` — добавить новое напоминание
- `/update <id> HH:MM` — изменить время напоминания (id — это НОМЕР из `/list`)
- `/delete <id>` — удалить напоминание (id — это НОМЕР из `/list`)

⚠️ **Важно:** `id` — это **номер** напоминания, а не название таблеток!  
📖 Подробнее: [Инструкция по использованию](USAGE_GUIDE.md)

## 📊 Примеры использования

### Пример 1: Посмотреть все напоминания

```
Вы: /list

Бот:
1: 06:00 — Эсциталопрам (утро) [активно]
2: 19:00 — Ярина плюс (вечер) [активно]
   ↑
  ID напоминания (это номер, НЕ название!)
```

### Пример 2: Изменить время Ярины с 19:00 на 19:30

```
Шаг 1: /list
       → Видим что Ярина это ID = 2

Шаг 2: /update 2 19:30
       → Бот: "Обновлено напоминание 2 на 19:30"

❌ НЕПРАВИЛЬНО: /update Ярина плюс 19:30
✅ ПРАВИЛЬНО:   /update 2 19:30
```

### Пример 3: Добавить новое напоминание

```
/settime 14:30 Витамины после обеда
```

### Пример 4: Удалить напоминание

```
Шаг 1: /list
       → Видим: 3: 14:30 — Витамины после обеда [активно]

Шаг 2: /delete 3

❌ НЕПРАВИЛЬНО: /delete Витамины
✅ ПРАВИЛЬНО:   /delete 3
```

## 🔧 Структура проекта

- `bot.py` — основной файл бота
- `reminders.db` — SQLite база данных с напоминаниями и историей
- `db_check.py` — утилита для проверки содержимого БД
- `cleanup_jobs.py` — утилита для проверки и диагностики джобов
- `check_job.py` — проверка работы job_queue

## 🗄️ База данных

### Таблица `reminders`
- `id` — уникальный идентификатор
- `chat_id` — ID чата пользователя
- `time` — время напоминания (HH:MM)
- `label` — метка/описание
- `active` — активно ли напоминание (1/0)

### Таблица `confirmations`
- `id` — уникальный идентификатор
- `reminder_id` — ID напоминания
- `chat_id` — ID чата
- `ts` — timestamp подтверждения
- `note` — заметка

### Проверка джобов

## 🔒 Решенные проблемы

### Дубликаты джобов ✅

**Проблема:** При использовании `/update` создавались дубликаты джобов, что приводило к многократной отправке одного напоминания.

**Решение:**
1. Каждому джобу присваивается уникальное имя: `reminder_{id}`
2. При обновлении времени старый джоб удаляется перед созданием нового
3. При старте бота проверяется наличие существующих джобов
4. При удалении напоминания джоб автоматически удаляется из очереди

### Управление джобами

- `settime` — создает джоб с уникальным именем
- `update` — удаляет старый и создает новый джоб
- `delete` — удаляет джоб из очереди и запись из БД
- `schedule_all` — при старте проверяет существующие джобы
