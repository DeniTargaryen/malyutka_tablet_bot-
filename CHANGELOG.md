### 2. 🐛 ИСПРАВЛЕНА КРИТИЧЕСКАЯ ПРОБЛЕМА: Дубликаты джобов

**Проблема:**
- При вызове `/update` создавался новый джоб, но старый НЕ удалялся
- Это приводило к отправке нескольких одинаковых напоминаний
- С каждым обновлением количество дубликатов увеличивалось

**Решение:**
1. ✅ Добавлены уникальные имена для всех джобов: `reminder_{id}`
2. ✅ Функция `/update` теперь удаляет старый джоб перед созданием нового
3. ✅ Функция `/delete` теперь удаляет джоб из очереди
4. ✅ Функция `schedule_all` проверяет существующие джобы перед созданием
5. ✅ Все функции создания джобов используют уникальные имена

**Изменения в коде:**

#### `settime` (строки 156-162)
- Добавлен параметр `name=f"reminder_{rid}"`

#### `setme` (строки 306-313)
- Добавлены параметры `name=f"reminder_{rid1}"` и `name=f"reminder_{rid2}"`
- Изменено время с 20:00 на 19:00

#### `update_cmd` (строки 340-352)
- Добавлено удаление старого джоба перед созданием нового
- Используется `get_jobs_by_name()` и `schedule_removal()`

#### `delete_cmd` (строки 176-185)
- Добавлено удаление джоба из job_queue
- Теперь джоб удаляется вместе с записью в БД

#### `schedule_all` (строки 260-266)
- Добавлена проверка существующих джобов
- Джобы создаются только если их еще нет в очереди
