# 🚀 Быстрый старт

## Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

## Шаг 2: Создайте файл .env

Создайте файл `.env` в корне проекта:

```
TELEGRAM_TOKEN=ваш_токен_от_BotFather
```

**Как получить токен:**
1. Откройте Telegram
2. Найдите бота @BotFather
3. Отправьте команду `/newbot`
4. Следуйте инструкциям
5. Скопируйте полученный токен в `.env`

## Шаг 3: Запустите бота

```bash
python bot.py
```

## Шаг 4: Настройте напоминания

1. Найдите своего бота в Telegram
2. Отправьте `/start`
3. Отправьте `/setme` для создания стандартных напоминаний:
   - 06:00 — Эсциталопрам
   - 19:00 — Ярина плюс

## ✅ Готово!

Теперь бот будет присылать напоминания каждый день в указанное время.

## 📝 Основные команды

- `/list` — показать все напоминания
- `/update 1 06:30` — изменить время первого напоминания на 06:30
- `/settime 14:00 Витамины` — добавить новое напоминание
- `/delete 3` — удалить напоминание с ID=3

## 🔧 Диагностика

Если что-то не работает:

```bash
# Проверить базу данных
python db_check.py

# Проверить джобы на дубликаты
python cleanup_jobs.py
```

## ⚠️ Важно!

- Бот должен быть запущен постоянно для работы напоминаний
- Используйте `screen` или `tmux` на сервере для фонового запуска
- Все время указывается по МСК (Московское время)
